# Standalone icon preparation prompts

Tool: built-in image generation. Reference: selected Voice Ribbon concept board.

## App icon

Edit target: reference concept board. Extract and faithfully reproduce ONLY the large aqua voice ribbon app icon from the upper center as a standalone production macOS icon asset. Preserve its exact ribbon shape, petrol blue tile, colors, materials and proportions. Remove all board, all labels and all other symbols. Square 1024x1024 image, tile centered, occupying about 88% width and height with equal transparent padding. Preserve rounded tile corners. True transparent pixels outside the tile, no white backdrop, no external drop shadow. Crisp polished high resolution. Do not redesign.

## Menu bar glyph

Edit target: reference concept board. Extract and faithfully reproduce ONLY the large BLACK voice ribbon menu bar glyph from lower right as a standalone production template icon. Preserve the recognizable ribbon waveform silhouette with tall central arch and lower side lobes. Solid pure black fill on TRUE TRANSPARENT background, no gray, shading or color. The narrow ribbon fold cutouts should remain transparent but clear and robust. No enclosing tile, no typography, no board or other icons. Center on a wide rectangular canvas with close even padding, one glyph only, crisp edges. Intended for macOS menu bar template icon.

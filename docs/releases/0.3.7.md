# QuietSpeech 0.3.7

Released: 2026-11-12

- Choose and remember a microphone in setup or Settings → Transcription. Reconnect a missing microphone or select another input before dictating.
- Check your microphone with a live input meter and a 15-second test that saves no audio.
- Automatically pause media while dictating and resume it after transcription finishes, when it was playing beforehand.
- See a dot on the menu bar icon when an update is available, with Install New Update as the first menu option.
- Fix the listening overlay intermittently disappearing when starting dictations in quick succession.
- Improve shortcut recovery when macOS interrupts keyboard access, with a Restore Shortcuts option.

# QuietSpeech 0.3.4

Released: 2026-11-09

- Tap to Toggle can now be a double-tap of your Hold to Talk key, or its own shortcut. Double-tap to start hands-free dictation, then tap once to stop.
- Shortcuts that use modifier keys now save correctly, and picking a function key is easier.
- Fixed freezes when dictation started, caused by macOS spell-checking.
- Dictation no longer starts twice, and the microphone no longer turns on late after you let go of the shortcut.
